# Code of conduct

Be kind, be specific, assume good faith. Critique code and ideas, not people.
Harassment, personal attacks and discriminatory language are not welcome and will
result in removal from the project spaces.

To report a problem, open a private security advisory on the repository or contact the
maintainers through the email on their GitHub profiles. Reports are handled
confidentially.

This project follows the spirit of the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
